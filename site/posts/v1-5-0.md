# Magnetares Notes v1.5.0: Code Snippets de Primeira Classe

Com a versão 1.5.0, o **Magnetares Notes** expande suas capacidades além de anotações tradicionais, tornando-se o canivete suíço definitivo também para **desenvolvedores**. Se você precisava de um repositório super rápido e nativo para organizar e gerenciar seus Code Snippets (Gists), essa versão foi feita para você!

## Monaco Editor Incorporado 💻
Fizemos uma integração profunda com o **Monaco Editor** — a exata mesma engine que alimenta o Microsoft VS Code. Isso significa que as suas Notas de Código agora possuem:
- Numeração de linhas e *Code Folding* nativo.
- Auto-fechamento de chaves, colchetes e parênteses.
- Um *Syntax Highlighting* perfeito e incrivelmente responsivo para seus scripts e códigos-fonte.

## Seletor de Linguagem Elegante e Color Badges
Como o Magnetares agora suporta dezenas de linguagens (Python, JS, Go, HTML, CSS, Bash, SQL, C++, etc.), no topo da sua nota você poderá alternar entre essas linguagens facilmente através de um menu suspenso nativo.

O mais divertido está na biblioteca (Sidebar): Ao criar uma nota de código, ela não usará o ícone de folha genérico. Injetamos suporte a biblioteca Devicons, e agora **um logotipo real colorido (Color Badge)** da sua linguagem ficará posicionado exatamente ao lado da sua nota, facilitando visualmente a localização no seu repositório pessoal!

## Criação Expressa de Códigos ⚡
Na barra de ferramentas lateral, não é mais preciso criar uma anotação vazia e depois alterar seu formato. O novo atalho `< >` cria uma nota configurada automaticamente para texto puro (ou a última linguagem que você estava usando). 
E, quando você precisar exportar a nota, nosso renderizador entende magicamente qual linguagem está sendo usada e exporta o arquivo com a extensão correta (por exemplo, `.py`, `.js`, `.go`, etc.).

## Botão Inteligente "Copiar Código"
Uma interface não estaria completa para desenvolvedores sem uma forma rápida de levar o código de volta ao trabalho. O novo toolbar introduz um botão direto de *Copiar Código*, com feedback visual vibrante.

Desenvolvedores também merecem uma ferramenta de uso pessoal linda, segura e sem telemetria. Divirtam-se codificando!

# Screenshots do Magnetares Notes

Adicione aqui as capturas de tela da aplicação com os seguintes nomes de arquivo:

- `editor.png`: Editor de texto principal (títulos, listas, checklists).
- `dark-mode.png`: Aplicação no modo escuro / noturno.
- `organization.png`: Visão de pastas, etiquetas (tags) e notas fixadas.
- `sync.png`: Painel / status de sincronização Turso ou backup.
- `settings.png`: Tela de configurações e preferências.

Os cards na página `screenshots.html` exibirão automaticamente um placeholder estilizado se alguma dessas imagens ainda não estiver presente nesta pasta.

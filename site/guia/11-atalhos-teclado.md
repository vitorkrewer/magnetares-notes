# Atalhos de Teclado

O Magnetares Notes foi desenvolvido para permitir que você realize quase todas as operações essenciais sem precisar tirar as mãos do teclado.

---

## 1. Navegação & Janela Principal

| Ação | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Focar na Busca de Notas** | `<kbd>Ctrl+F` | `<kbd>Cmd+F` |
| **Criar Nova Nota de Texto Rico** | `<kbd>Ctrl+N` | `<kbd>Cmd+N` |
| **Forçar Salvamento Imediato** | `<kbd>Ctrl+S` | `<kbd>Cmd+S` |
| **Imprimir / Gerar PDF de Alta Fidelidade** | `<kbd>Ctrl+P` | `<kbd>Cmd+P` |
| **Fechar Janela / Cancelar Seleção** | `<kbd>Esc` | `<kbd>Esc` |

## 3. Fórmulas Matemáticas & Ciências

| Ação | Atalho / Gatilho | Descrição |
| :--- | :--- | :--- |
| **Abrir Editor de Fórmulas** | Botão `$\Sigma$` na toolbar | Abre modal KaTeX com teclado visual de símbolos |
| **Converter Seleção em Fórmula** | Selecionar texto + Botão `$\Sigma$` | Encapsula o texto selecionado diretamente no modal de equação |
| **Confirmar Inserção de Fórmula** | `<kbd>Ctrl+Enter` ou `<kbd>Cmd+Enter` | Insere a fórmula matemática na nota e fecha o modal |
| **Editar Fórmula Existente** | `Duplo clique` na fórmula | Reabre o modal para ajuste rápido da equação |
| **Editar Diagrama Mermaid** | `Duplo clique` no diagrama | Alterna entre o modo de visualização e edição do código Mermaid |

## 4. Listas & Tarefas

| Ação | Gatilho | Descrição |
| :--- | :--- | :--- |
| **Adicionar Tarefa Rápida** | `<kbd>Enter` no campo Quick-Add | Cria a tarefa com prioridade e prazo definidos |
| **Concluir Tarefa** | `Clique` na caixa de seleção | Marca a tarefa como concluída e atualiza os contadores |
| **Adicionar Subtarefa** | `<kbd>Enter` no campo de subtarefa | Insere novo item no checklist interno da tarefa |
| **Fechar Painel Inspector** | `<kbd>Esc` ou botão fechar | Fecha a visualização detalhada da tarefa |

---

## 5. Modo Foco (Janela Independente)

| Ação | Tecla / Ação | Descrição |
| :--- | :--- | :--- |
| **Fechar Janela e Devolver Edição** | `<kbd>Esc` | Salva o conteúdo no SQLite e reabre a nota na janela principal |
| **Salvar Alterações** | `<kbd>Ctrl+S` ou `<kbd>Cmd+S` | Grava as mutações pendentes imediatamente no banco |
| **Fixar / Desafixar no Topo** | Ícone de `Pin` na barra | Mantém a janela flutuando sobre navegadores e players de vídeo |

Ajuda e Tutoriais

Entenda como as engrenagens do Magnetares Notes funcionam. Dicas rápidas, configuração de nuvem e respostas às perguntas mais frequentes.

☁️

Onde meus dados são salvos?

Atualmente, o Magnetares Notes utiliza o Turso (SQLite Edge Database) como provedor de banco de dados em nuvem para sincronização.

O aplicativo opera de forma Local-First: isso significa que a fonte da verdade dos seus dados é o banco local SQLite gravado no seu computador. A nuvem é totalmente opcional.

🔑

Como configuro a sincronização com o Turso?

Para ativar a sincronização, crie uma conta gratuita no Turso.

  • Crie um banco de dados no Turso (ex: magnetares-db).
  • Gere e copie um Token de Acesso.
  • Copie a URL do banco de dados (libsql://...).
  • No Magnetares, acesse Configurações > Nuvem e cole essas informações.
🗑️

Notas apagadas e Tombstones

O Magnetares utiliza Tombstones para exclusão segura. Quando você move uma nota para a Lixeira ou apaga definitivamente, o aplicativo não deleta o dado local imediatamente se houver sincronização pendente.

Ele cria uma "lápide" (tombstone) e avisa ao Turso para também removê-la. Só após a confirmação da nuvem a nota é deletada do disco rígido, evitando "notas zumbis".

</>

Notas de Texto vs Notas de Código

Use o botão + para criar notas de texto (ricas), ou o ícone </> para criar Snippets de Código.

O editor de Código usa o Monaco Editor (o mesmo do VS Code) oferecendo autocomplete, syntax highlighting e ícones para cada linguagem (Go, JS, Python, etc).

🏷️

Sugestões de Etiquetas (Tags)

Ao criar uma tag (abaixo do título), comece a digitar para ver um menu suspenso de tags existentes. Se a palavra não existir, aperte Enter para criar uma etiqueta nova instantaneamente.

📌

Mural de Stickers

Um quadro livre na barra lateral para anotações rápidas em post-its coloridos. Você pode criar vários quadros, arrastar as notas (drag & drop), alterar as cores em tons pasteis e fixá-las (pin) no topo.

🎨

Formatação Rica e Cores

O Magnetares oferece opções avançadas no editor rich-text: selecione textos para ver o menu flutuante. Você pode alterar o alinhamento, definir espaçamento entre linhas e colorir a fonte utilizando uma paleta de 20 cores customizadas feitas para combinar com o design.

Versão Portátil (Pendrive)

A versão Portátil (.zip) é 100% autocontida. Ao descompactar no seu pendrive ou pasta externa, o aplicativo detecta automaticamente o diretório data/ local e mantém todo o seu banco de dados (SQLite) e configurações salvos dentro do próprio pendrive.

Você pode conectar o pendrive em qualquer computador Windows e abrir suas notas diretamente sem deixar rastros no sistema host. Dica: lembre-se de fechar o Magnetares antes de ejetar o pendrive com segurança!
